Tick Confirm on the intervals you have signed off, then build the package. It contains the SNRO intervals, the grouping assignment, the account group mapping and a runbook — only for confirmed rows.

How to apply this

  1. SNRO, object BU_PARTNER — create or change each interval in the table above, external where the Ext column is marked.
  2. SPRO > Cross-Application Components > SAP Business Partner > Business Partner > Basic Settings > Number Ranges and Groupings > Define Groupings and Assign Number Ranges — assign each interval to its grouping.
  3. SPRO > … > Customer/Vendor Integration > Define Number Assignment for Direction Customer/Vendor to BP — route each account group into its grouping.
  4. Re-run the analysis. CFG-05, CFG-06 and CFG-08 are the checks that confirm the design holds.

Intervals are proposed from the number band each grouping actually occupies, rounded outward to a whole 100,000 block with headroom left above the highest used number.
